# BharatGPT Mini 🇮🇳

A simple AI-inspired app based on Indian knowledge systems.

## Features
- Chat interface
- Multiple modes (Yoga, Ayurveda, Philosophy, Vedic Maths)
- Dockerized
- CI/CD ready

## Run locally
npm install
node app.js

## Docker

docker build -t bharatgpt .
docker run -p 3000:3000 bharatgpt
